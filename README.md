# Liftnet2 organization defaults

GitHub uses the files here for every Liftnet2 repository that has no file of its own:

| File | Used as |
|---|---|
| `.github/pull_request_template.md` | the description a new pull request starts with |

A repository's own `.github/pull_request_template.md` replaces this one entirely, so a repository template should start
with the same **Goal** block (goal, why, done when), followed by that repository's own checklist.

This repository is public because GitHub reads organization defaults only from a public `.github` repository. Keep
anything private out of it.
